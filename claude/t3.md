# T3 Code

This session runs in a T3 Code thread, so the `t3-code` MCP tools are available.

- For longer agent work and every non-Claude model, use T3's `delegate_task` instead of `homebased`, so the work shows under this thread. Keep `homebased` for command workloads, Fleet machines, the GPU queue, and `after` chains.
- To wait on homebased tasks, arm `Monitor` on `homebased task wait <id> [<id> ...]`, which prints only task events, pass the Monitor's task id to `t3_background_wait`, and end the turn, so T3 lists the thread under Waiting.
