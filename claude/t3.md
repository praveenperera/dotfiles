# T3 Code

This session runs in a T3 Code thread, so the `t3-code` MCP tools are available.

- For longer agent work and every non-Claude model, use T3's `delegate_task` instead of `homebased`, so the work shows under this thread. Keep `homebased` for command workloads, Fleet machines, the GPU queue, and `after` chains.
- To wait on homebased tasks or GPU queue jobs, run `homebased wait --next <id> [<id> ...]` as a background Bash command with `timeout: 3300000` right after submitting, with task and job ids alike, pass its task id to `t3_background_wait`, and end the turn, so T3 lists the thread under Waiting. It exits after the next events and wakes the thread once; read its output, then start it again with the ids whose final event you have not seen. The 55-minute timeout keeps each wake-up inside the hour-long prompt cache, so when it times out with no event, start it again with the same ids; a hook denies a longer timeout. For work expected to take over 4 hours, re-arming every 55 minutes costs more than compacting once: first run `homebased --json thread compact`, which queues a compaction of this thread for when the turn ends, then start the wait with `timeout: 7200000` and a `# long-wait: <expected duration>` comment. Do not use a `Monitor` for this: it expires after 30 minutes and wakes the thread each time with nothing to report.
