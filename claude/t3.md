# T3 Code

This session runs in a T3 Code thread, so the `t3-code` MCP tools are available.

- For longer agent work and every non-Claude model, use T3's `delegate_task` instead of `homebased`, so the work shows under this thread. Keep `homebased` for command workloads, Fleet machines, the GPU queue, and `after` chains.
- To wait on homebased tasks or GPU queue jobs, run `homebased wait --next <id> [<id> ...]` as a background Bash command with `timeout: 7200000` right after submitting, with task and job ids alike, pass its task id to `t3_background_wait`, and end the turn, so T3 lists the thread under Waiting. It exits after the next events and wakes the thread once; read its output, then start it again with the ids whose final event you have not seen. Do not use a `Monitor` for this: it expires after 30 minutes and wakes the thread each time with nothing to report.
