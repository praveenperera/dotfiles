# Track C: native model runtime

Porting a whole model off PyTorch or ONNX Runtime. Shorthands as in SKILL.md.

- **Know which kind of model it is.** Step loops, many small ops and multi-stage pipelines gain 20-30x over a generic runtime. A GEMM-bound encoder gains about 1.05-1.1x on kernels, and the win is in the glue. Do the floor arithmetic first.
- **Where the time usually is:** host round trips and re-uploads, CPU fallback ops, one launch per op, host-driven decode loops with a sync per step, CPU glue, and stages run one after another. What pays: tensors kept on the GPU, CUDA graphs where the GPU idles, the decode loop as small fused kernels, host prep overlapped with the GPU, batching, and glue fused into neighbors.
- **Look for work the structure makes redundant.** When every cross-attention layer's K/V are linear maps of one encoder output, absorbing the weights cuts decode bytes. Reuse K/V a previous stage already cached. Price each at the real token counts first.
- **Choose precision per layer and test each contract.** BF16 tensor cores need BF16 storage, conversions are a hidden cost, and a global math mode leaks into layers promised FP32. Check the framework's defaults per op family (cuDNN convs default to TF32, matmul doesn't). Price FP8 with a fake-quant pass on the end gates before building it, and probe its rates rather than assume them.
- **Check parity per layer, not just at the output.** Deep stacks amplify rounding. Compare each kernel with f64 on its exact rounded inputs, and gate a layer whose framework error is zero by construction against f64, not a multiple of zero. On a deep stack, judge chained error against the worst of several exact-in-real-arithmetic reference reruns. Match the framework's arithmetic, including FMA contractions (`torch.linspace` is `start + i*step` as an FMA on CUDA).
- **Gate reduced precision per stage, and around argmax picks.** Give a BF16 backbone and heads on exact inputs their own bounds. Excuse a near-tie flip only within a margin, cap how many, and keep the mean limit on every frame. Check two reduced-precision paths against a common truth, not each other.
- **Make parity fixtures trustworthy.** A stage test that runs only when its fixture key exists passes on a dump without it, so count each stage's checks. Assert mask lengths before an IoU and fail non-finite scores. Clone in framework hooks, since saved tensors see later in-place edits. Feed the reference's decoded audio or image to parity tests, golden-test the tokenizer including special tokens, check weights against a committed schema, and reject config options the engine doesn't implement.
- **Pin the vendor library versions the reference uses** when parity is tight: load the framework's exact cuBLAS build, since another version may pick different GEMM kernels.
- **The speed phase is a hill climb**: open `PW/playbooks/gpu-hill-climb.md` once the parity gate passes.
- **Price a second stream or engine by timing the real work list on N of them in one queue job**, not from idle gaps; the share of kernel time in full-wave grids predicts the gain. The default stream priority is the lowest, so raise decode's priority for a background stream to rank below it. `cuMemcpyDtoHAsync` to pageable memory blocks until its stream drains, and other threads' pageable copies queue behind it; use pinned buffers. A step result that sets the next batch's composition can't move off the critical path without changing output.
- **Bound shape caches by bytes** and share scratch across shapes, then count misses before blaming kernels. Serialize load, capture and teardown with one process-wide lock, and test concurrency under full CPU load. Capture CUDA graphs at load, before other models launch work, with static buffers per thread; never share one graph across threads. In PyTorch, capture under `torch.no_grad()`.
- **Build the safe Rust layer early:** `Pod`-only transfers, host buffers kept alive through async copies, buffers that keep their stream alive, async copies that accept only the calling handle's buffers, loader errors instead of panics, geometry validated at the API boundary, and every GPU step checked before its results update host state.
- **Time results through the binding users call, and hand large host outputs over without copies**: one contiguous, recycled buffer viewed through the buffer protocol, not numpy copies, which stall on huge-page compaction. Count `compact_stall` in `/proc/vmstat` around slow calls.
- **Time recurrences inside a CUDA graph, and check tiny ones against the CPU.** CUDA-event timing of a step reads host launch time; some tiny steps are faster on the CPU.
