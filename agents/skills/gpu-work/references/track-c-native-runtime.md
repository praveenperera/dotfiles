# Track C: native model runtime

Porting a whole model off PyTorch or ONNX Runtime (speakrs, scriptrs, sam3rs, whisperdrz). Shorthands as in SKILL.md.

- **Know which kind of model it is.** Step loops, many small ops and multi-stage pipelines gain 20-30x over a generic runtime (speakrs). A GEMM-bound encoder gains about 1.05-1.1x on kernels, and the win is in the glue (SAM 3 prompts 1.3-15x). Do the floor arithmetic first. (`SMR/generic-vs-specialized-kernels.md`)
- **Where the time usually is:** host round trips and re-uploads, CPU fallback ops, one launch per op, host-driven decode loops with a sync per step, CPU glue, and stages run one after another. What paid: tensors kept on the GPU, CUDA graphs where the GPU idles, the decode loop as small fused kernels, host prep overlapped with the GPU, batching, and glue fused into neighbors.
- **Look for work the structure makes redundant.** When every cross-attention layer's K/V are linear maps of one encoder output, absorbing the weights can cut decode bytes by n_layers x 2 x d_head·n_head / d_model. Reuse K/V a previous stage already cached (whisperdrz's DTW pass reuses prefill's, bit-identical). Price each at the real token counts first: absorption cost 5x more at DTW's 415 tokens a row.
- **Choose precision per layer and test each contract.** BF16 tensor cores need BF16 storage, conversions are a hidden cost, and a global math mode leaks into layers promised FP32. Check the framework's defaults per op family (cuDNN convs default to TF32, matmul doesn't). Price FP8 with a fake-quant pass on the end gates before building it, and probe its rates rather than assume them: SAM 3's ViT failed all five recipes. (Lessons §7)
- **Check parity per layer, not just at the output.** Deep stacks amplify rounding (about 3x per layer in Parakeet's last four). Compare each kernel with f64 on its exact rounded inputs, and gate a layer whose framework error is zero by construction (both modes run the same cuFFT) against f64, not a multiple of zero. On a deep stack, judge chained error against the worst of several exact-in-real-arithmetic reference reruns. Match the framework's arithmetic, including FMA contractions (`torch.linspace` is `start + i*step` as an FMA on CUDA). (Lessons §8)
- **Gate reduced precision per stage, and around argmax picks.** Give a BF16 backbone and heads on exact inputs their own bounds. Excuse a near-tie flip only within a margin, cap how many, and keep the mean limit on every frame. Check two reduced-precision paths against a common truth, not each other. (`SMR/sam3rs-decisions.md`)
- **Make parity fixtures trustworthy.** A stage test that runs only when its fixture key exists passes on a dump without it, so count each stage's checks. Assert mask lengths before an IoU and fail non-finite scores, which otherwise read as absent and score IoU 1. A framework hook that saves without cloning sees later in-place edits; clone in the hook. Feed the reference's decoded audio or image to parity tests, golden-test the tokenizer including special tokens, check weights against a committed schema, and reject config options the engine doesn't implement. (Lessons §7, §10)
- **Pin the vendor library versions the reference uses** when parity is tight: load the framework's exact cuBLAS build rather than whatever the binding finds, since a different version may pick different GEMM kernels.
- **The speed phase is a hill climb**: open `PW/playbooks/gpu-hill-climb.md` once the parity gate passes.
- **Price a second stream or engine by timing the real work list on N of them in one queue job**, not from idle gaps; the share of kernel time in full-wave grids predicts the gain better than stream idle. The default stream priority is the lowest, so a background stream ranks below decode only if decode's is raised. `cuMemcpyDtoHAsync` to pageable memory blocks until its stream drains, and other threads' pageable copies queue behind it; use pinned buffers. A step result that sets the next batch's composition (whisperdrz DTW) can't move off the critical path without changing output.
- **Bound shape caches by bytes** and share scratch across shapes, then count misses before blaming kernels. Serialize load, capture and teardown with one process-wide lock, and test concurrency under full CPU load. Capture CUDA graphs at load, before other models launch work, with static buffers per thread (Docling TableFormer lost 21-33% of cells sharing one graph across 4 threads). In PyTorch, capture under `torch.no_grad()`, or each captured output keeps its autograd graph alive. (Lessons §8)
- **Build the safe Rust layer early:** `Pod`-only transfers, host buffers kept alive through async copies, buffers that keep their stream alive, async copies that accept only the calling handle's buffers, loader errors instead of panics, geometry validated at the API boundary, and every GPU step checked before its results update host state. (Lessons §7, §9)
- **Time results through the binding users call, and hand large host outputs over without copies.** numpy copies of 4-5 MB sam3rs masks cost 10-1100 ms from huge-page compaction stalls; one contiguous buffer viewed through the buffer protocol, recycled, took a call from 249-319 to 14 ms. Count `compact_stall` in `/proc/vmstat` around slow calls.
- **Time recurrences inside a CUDA graph, and check tiny ones against the CPU.** CUDA-event timing of cuDNN's BiLSTM read host launch (8 µs a step at any batch; 2.8 µs in a graph). A Silero VAD step was faster on the CPU. (`SMR/kokoro-baselines-2026-11-01.md`)
